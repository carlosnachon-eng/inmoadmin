Audit findings
- Instagram: encrypted capture, authorized reader, public manual reply and
  legacy automation action journal exist. DMs and comments are separate.
- Facebook receiver handles entry.messaging; feed comment changes are ignored.
  No operational Facebook comment capture/reader was found. UI explicitly says pending.
- No accredited publication-to-property registry was found. Never infer a
  property from caption, proximity, text or a caller-supplied ID.
- Local absence of a reply does not establish absence of external responses.
  The live adapter marks replies_verified=false. It cannot propose publication.
- Legacy automateBusinessComment references dryRun without accepting it in
  its arguments; the batch caller does not pass it. This path is NOT called or
  repaired here because unblocking it could enable an existing generic sender.
  Requires a separate guarded migration before any automation activation.
