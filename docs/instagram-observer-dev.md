# Instagram observer — DEV certification

## Scope

New independent Pages Router endpoint `/api/webhooks/instagram`. OFF by default;
explicitly refuses Vercel production, non-DEV Supabase URLs and foreign IG accounts.
No WhatsApp/Respond receiver changes. No queue, sender, model, identity bridge,
commercial routing, Graph calls, moderation or subscriptions.

GET validates the separate verify token and returns a numeric challenge. POST checks
HMAC SHA-256 over original bytes before parsing; 256 KiB / 100 observations maximum.
Only exact account `17841440384433670` is accepted. A mixed-scope batch fails whole.
200 requires durable receipt + all normalized metadata committed in one RPC.
Persistence errors return 503. Signature errors return 401. Scope errors return 403.

## Privacy / incomplete evidence

Stores native message/comment/media/parent IDs in a private schema, timestamp,
kind, HMAC subject pseudonym and observation hash. No text, usernames, profile,
attachment URL, payload or token is persisted/logged. This phase certifies transport
metadata, not Inbox content ingestion. A native echo is unattributed, never human.
Comment parent/media references are retained, but no root is inferred from an absent
parent. They cannot enter the existing thread projection until the root is proven.
DMs and comments have distinct kinds; no automatic cross-thread merge.

An observation fingerprint deduplicates identical deliveries only. It is NOT a
business effect key, identity match, timestamp/text heuristic or cross-provider
deduplication. Different observations of the same native ID remain separate.
Unsupported fields are counted as ignored; do not claim full edit/status coverage.
